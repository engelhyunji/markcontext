바코드 사이즈 설정 안내

  • 바코드 사이즈 설정 시 실제 입력 값(픽셀)과 출력 값(Cm)이 상이합니다.
    (예: 입력 300/90 → 출력 15.9cm / 1.6cm)
  • 출력 값의 단위는 cm이며, 소수 첫째 자릿수에서 반올림한 값을 나타냅니다.
  • 기본 설정 값: 가로 300 / 세로 90
  • 2D 바코드의 경우 출력 시 오차 범위가 존재합니다. (가로: 0.3 / 세로: 0.1)
